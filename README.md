# لانشر "نور" لشاشات Android TV

واجهة رئيسية خفيفة جداً (مرسومة على Canvas واحد، بدون أي مكتبات خارجية) مصممة لشاشة Toshiba / HiSmart ‏Android TV 11 بذاكرة 1 جيجا.

**فيها:** ساعة وتاريخ ميلادي وهجري، مواقيت الصلاة أوفلاين (الهيئة المصرية)، عدّاد الصلاة القادمة (والإفطار والإمساك في رمضان)، المحراب، صف مفضلة وصف "المزيد" تعدّلهم بنفسك، شاشة "كل التطبيقات"، شاشة مواقيت وقبلة، إذاعة القرآن، وحالة الإنترنت.

---

## 1) بناء ملف APK (مجاناً على GitHub، من غير ما تثبّت أي حاجة)

1. اعمل حساب على https://github.com (لو معاكش).
2. اعمل Repository جديد (اسمه مثلاً `noor-launcher`).
3. من صفحة الـ Repository اضغط **Add file ← Upload files** واسحب **كل محتويات** فولدر المشروع (بما فيها فولدر `.github` المخفي) ثم **Commit changes**.
   - لو الفولدر المخفي `.github` ما اتسحبش من المتصفح: من **Add file ← Create new file** اكتب في الاسم `.github/workflows/build.yml` والصق محتوى الملف.
4. اضغط تبويب **Actions**، هتلاقي "Build APK" شغّال (أو اضغط **Run workflow**). ياخد 3 إلى 6 دقايق.
5. افتح التشغيل الخلصان ونزّل من **Artifacts** الملف `NoorLauncher-APK` (zip فيه `NoorLauncher.apk`).

> بديل: افتح المشروع في **Android Studio** واختر **Build ← Build APK(s)**.

## 2) تثبيت الـ APK على الشاشة

اختار طريقة واحدة:

- **فلاشة USB:** انسخ الـ APK على فلاشة، وصّلها بالشاشة، وافتح **File Manager+** (موجود عندك) وافتح الملف. أول مرة هيطلب تسمح للتطبيق بالتثبيت من مصادر خارجية، وافق.
- **ADB من الكمبيوتر:** فعّل وضع المطور (الإعدادات ← تفضيلات الجهاز ← حول ← اضغط على "Build" 7 مرات)، وفعّل **USB debugging / ADB debugging** من خيارات المطور، وبعدين:
  ```
  adb connect عنوان_IP_الشاشة:5555
  adb install -r NoorLauncher.apk
  ```

بعد التثبيت هتلاقي التطبيق باسم **نور** في قائمة التطبيقات.

## 3) تخليه الواجهة الافتراضية (يفتح أول ما الشاشة تشتغل)

**الطريقة الأولى (الأسهل):** اضغط زر **Home** في الريموت، لو ظهر اختيار "الشاشة الرئيسية" اختار **نور** ثم **دائماً / Always**.

**الطريقة الثانية (لو الشاشة ما سألتش):** من ADB، أمر واحد:
```
adb shell cmd package set-home-activity com.noor.launcher/.MainActivity
```

**الطريقة الثالثة (حل أخير، لو الشاشة بتفضل ترجع للواجهة الأصلية):** تعطيل الواجهة الأصلية (من غير حذفها). **ثبّت "نور" وجرّبه الأول وتأكد إنه شغال**، بعدين:
```
adb shell pm list packages | findstr /i "launcher home"      (ويندوز)
adb shell pm list packages | grep -i -E "launcher|home"      (ماك/لينكس)
adb shell pm disable-user --user 0 اسم_الباكدج_الأصلي
```

## 4) الرجوع للواجهة الأصلية

- لو استخدمت الطريقة الأولى أو الثانية: امسح تطبيق "نور" (الإعدادات ← التطبيقات) والشاشة هترجع لواجهتها الأصلية لوحدها.
- لو عطّلت الواجهة الأصلية:
  ```
  adb shell pm enable اسم_الباكدج_الأصلي
  ```

## 5) التخصيص

كل التعديلات في ملف `app/src/main/java/com/noor/launcher/Config.java`:

- `RADIO_URL`: رابط بث الإذاعة (بدّله لو الرابط الحالي مش شغال).
- `OFFSET_MIN`: ضبط المواقيت بالدقايق (مثلاً لو عايز المغرب +1 دقيقة).

والباقي من الشاشة نفسها:

- **المدينة:** من شاشة المواقيت (زر "مواقيت اليوم والقبلة")، السهم يمين/يسار أو OK.
- **المفضلة وصف المزيد:** افتح **كل التطبيقات**، اضغط **OK مطولاً** على أي تطبيق واختار.
- **إزالة تطبيق:** اضغط OK مطولاً عليه في الشاشة الرئيسية.
- **خط عربي مخصص:** حط ملف خط باسم `ui.ttf` في `app/src/main/assets/fonts/` وأعد البناء.
- **تعديل التاريخ الهجري:** من شاشة المواقيت (بالأسهم)، لو التاريخ مختلف يوم عن الرؤية في بلدك.

## ملاحظات

- المواقيت محسوبة أوفلاين بطريقة الهيئة المصرية (فجر 19.5° / عشاء 17.5°)، وللخليج بطريقة أم القرى. اتطابقت مع التواريخ والمواقيت اللي في الصور المرجعية.
- الساعة والمواقيت بتتحسب بتوقيت المدينة المختارة (القاهرة = Africa/Cairo بالتوقيت الصيفي). لو لقيت المواقيت فرقها ساعة كاملة، معناها إن بيانات المناطق الزمنية في الشاشة قديمة؛ عدّل `OFFSET_MIN` أو قولّي.
- الإذاعة بتشتغل طول ما التطبيق في الذاكرة، والشاشة ممكن تقفلها لو الذاكرة قلّت.
